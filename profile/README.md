# Yaguana

**Le portail numérique de Léogâne, Haïti.**
Un projet open source, par la communauté, pour la communauté.

[yaguana.org](https://yaguana.org) · [Facebook](https://www.facebook.com/yaguanaOrg) · [YouTube](https://www.youtube.com/@YaguanaOrg) · Français · Kreyòl · English

---

## À propos

Yaguana développe [yaguana.org](https://yaguana.org), le portail numérique de
la commune de Léogâne et de ses treize sections communales. Il réunit en un
seul endroit l’information sur la commune : son histoire, ses institutions,
ses personnalités, ses actualités et sa météo, dans les trois langues de ses
habitants et de sa diaspora.

Le nom du projet reprend celui de Yaguana, la ville taïno dont Léogâne est
issue.

## Ce que propose le portail

| | |
|---|---|
| **La commune** | Présentation, histoire et treize sections communales |
| **Les institutions** | Mairie, député, écoles, centres de santé, services publics |
| **Les personnalités** | Les femmes et les hommes qui ont marqué Léogâne |
| **Les actualités** | Les nouvelles de la commune et de chaque section |
| **La météo** | Les prévisions pour chaque section communale |
| **La newsletter** | Les nouvelles de la commune par courriel |

## Contribuer

Le portail se construit avec ceux qui connaissent Léogâne. Les contributions
sont les bienvenues, avec ou sans compétences techniques :

- **Contenu** : actualités, informations sur les institutions, portraits de
  personnalités.
- **Photographies et documents anciens** : photos, lettres, journaux, cartes.
  Une copie numérique suffit ; l’original reste chez son propriétaire.
- **Histoire et mémoire** : témoignages et récits, accompagnés de leurs
  sources.
- **Traduction** : en kreyòl et en anglais.
- **Développement** : Next.js, TypeScript et Tailwind CSS.

Le guide de contribution, [CONTRIBUTING.md](https://github.com/yaguana-org/.github/blob/main/CONTRIBUTING.md), précise les
étapes et les règles du projet.

## Nos principes

- **Ouvert** : le code est publié sous licence libre GNU AGPL-3.0, et les
  textes de cette page sous licence CC BY-SA 4.0.
- **Vérifié** : chaque information doit pouvoir être sourcée.
- **Respectueux** : aucune photo ni aucun portrait n’est publié sans
  l’accord des personnes concernées.
- **Accessible** : conçu d’abord pour le téléphone, en trois langues.

## Statut

Le portail est en construction. Le code source sera publié dans cette
organisation à son ouverture. D’ici là, pour participer ou proposer un
contenu, contactez-nous depuis [yaguana.org](https://yaguana.org).
